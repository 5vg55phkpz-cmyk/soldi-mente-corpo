# Soldi, Mente e Corpo

Dashboard per monitorare il benessere complessivo: finanza, crescita mentale e salute fisica.

## Funzioni principali

- Soldi: budget settimanale, entrate, uscite, risparmi e obiettivi finanziari
- Mente: focus, meditazione, lettura, apprendimento e routine mentale
- Corpo: allenamenti, passi, sonno, energia e attività fisica
- KPI principali: trend giornaliero, progressi e obiettivi da raggiungere

## Struttura del progetto

- `index.html` – dashboard principale
- `styles.css` – stile grafico e layout
- `script.js` – dati e rendering dinamico

## Esecuzione locale

Puoi aprire direttamente `index.html` nel browser oppure usare un server locale:

```bash
cd /percorso/della/repository
python3 -m http.server 8000
```

Poi apri:

```text
http://localhost:8000
```

## Obiettivo del progetto

Creare un'applicazione semplice e visiva che aiuti a mantenere equilibrio tra:

- stabilità economica
- chiarezza mentale
- salute fisica

## Roadmap

1. Dashboard principale con KPI
2. Sezione finanziaria e obiettivi di risparmio
3. Sezione mentale con routine e focus
4. Sezione fisica con allenamenti e attività
5. Possibili evoluzioni: login, salvataggio dati, grafici avanzati e sincronizzazione
